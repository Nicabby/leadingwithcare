# Leading with Care

Course companion sites for the Leading with Care program (Elevate Adolescence Program).

- [`binder/`](binder) — Learner Binder (live: https://leadingwithcare.vercel.app): lesson reviews, fillable binder activities, the Care-Centered Practice Toolkit, practice knowledge checks, notes, and backup/restore.
- [`facilitator/`](facilitator) — Facilitator Guide (live: https://leadingwithcare-4v1e.vercel.app): live session plans, handouts, answer key, and a PDF edition.

Each folder is a standalone Next.js site. See its README to run, edit, or deploy it. When deploying to Vercel, create one project per folder and set its **Root Directory** to `binder` or `facilitator`.
